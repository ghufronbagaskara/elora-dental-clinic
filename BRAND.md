# Logo Elora Smile Clinic

Tool: imagegen bawaan, bukan fallback CLI/API. Output menggunakan alpha transparan, diverifikasi sebagai PNG RGBA 1254 × 1254 dengan rentang alpha 0–255.

File proyek: `assets/brand/elora-symbol.png`. File ini dipakai untuk sidebar, favicon, dan Apple touch icon. Wordmark Elora tetap mengikuti desain sidebar asli.

## Prompt final

Use case: logo-brand. Create one original brand symbol for Elora Smile Clinic, intended as a small website logo and favicon. Isolated flat two-color vector-like artwork on a genuinely transparent background. A graceful dental arch/smile formed from two carefully balanced interlocking botanical curves, suggesting care and a small leaf through negative space. Deep forest green #18392f with a restrained sage accent #8da998. Professional, quiet, soft Scandinavian dental identity, distinctive silhouette that remains legible at 32 pixels. Center the symbol in a square image with modest padding. No lettering, no E monogram, no text, no tooth clip-art, no sparkles, no gradients, no shadows, no 3D mockup, no decorative frame. Return a single clean mark, not a sheet of options.
